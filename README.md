CodeAlpha Task Automation with Python

Project Overview

This project automates a simple repetitive task using Python. It organizes JPG images from a source folder into a separate destination folder.

Project Objective

The objective is to reduce manual effort by automatically identifying and moving JPG files into an organized folder.

Technologies Used

* Python
* os module
* shutil module
* File handling

How It Works

1. Reads JPG files from the source_images folder.
2. Creates an organized_images folder if it doesn’t exist.
3. Identifies all JPG files.
4. Moves the images into the destination folder.
5. Displays a success message.

Project Structure

* task_automation.py – Main Python script.
* source_images/ – Contains the original JPG images.
* organized_images/ – Stores the organized images.

How to Run

Run the following command in your terminal:

python task_automation.py

Output

All JPG images are successfully organized into the destination folder.
